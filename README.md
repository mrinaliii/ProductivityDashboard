🚀 Productivity Dashboard 📊🎧
==============================

A modern **Productivity Dashboard Web Application** designed to help users stay focused, organized, and productive in a calming workspace environment.

The application combines **task management, focus timing, and ambient lofi music** inside a visually immersive dashboard enhanced with a looping background video.

🌐 **Live Demo:**\
<https://mrinaliii.github.io/ProductivityDashboard/>

* * * * *

✨ Features
----------

-   ✅ **To-Do List Manager** --- Add and manage daily tasks easily

-   ⏱️ **Pomodoro Timer** --- Improve focus using structured work sessions

-   🎧 **Lofi Music Player** --- Ambient background music for better concentration

-   🎥 **Looping Background Video** --- Creates a relaxing productivity environment

-   📱 **Responsive Interface** --- Works across different screen sizes

-   ⚡ **Real-Time Interactivity** using Vanilla JavaScript

-   🌐 Fully browser-based (no backend required)

* * * * *

🛠️ Tech Stack
--------------

-   HTML5

-   CSS3

-   JavaScript (Vanilla JS)

-   GitHub Pages (Deployment)

🚀 Installation & Setup
-----------------------

1.  Clone the repository

```
git clone https://github.com/mrinaliii/ProductivityDashboard.git

```

1.  Navigate into the project folder

```
cd ProductivityDashboard

```

1.  Open the application

Simply open:

```
index.html

```

in any modern web browser.

No dependencies or installation steps are required.

* * * * *

🎯 How to Use
-------------

-   Open the dashboard using the live link or locally.

-   Add and manage tasks using the **To-Do List**.

-   Start the **Pomodoro Timer** to maintain focused work sessions.

-   Play **lofi music** for a distraction-free study or work environment.

-   Enjoy a calming visual experience with the looping background video.
